# Synthetic MLCC datasets and the v1 bundle

12,000 fictional X7R capacitors in 60 batches, leakage current in µA at ten checkpoints from 0 h to 168 h, generated by `scripts/generate_mlcc_data.py`. Nothing here was measured on hardware.

| Files | Use |
|---|---|
| `train_*`, `calibration_*`, `test_*` | Whole-batch splits: fit, calibrate intervals, evaluate once |
| `demo_early.csv`, `demo_outcomes.csv` | The upload the dashboard demonstrates, and its later readings for the reveal |
| `stress_low_prevalence_*`, `stress_unseen_condition_*` | Rare-defect and shifted-condition stress sets |
| `model_bundle/` | The first prototype bundle (`mlcc-pilot-1.0`); superseded by `outputs/mlcc_v2` |

Column meanings: [DATA_DICTIONARY.md](DATA_DICTIONARY.md). What the generator assumes and does not claim: [SOURCES_AND_ASSUMPTIONS.md](SOURCES_AND_ASSUMPTIONS.md). History of the first prototype: [START_HERE.md](START_HERE.md).
